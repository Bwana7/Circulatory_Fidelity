# Archived Simulation Data

This directory contains intermediate or alternative-granularity simulation files that are not part of the main analysis but are retained for reference.

## Contents

| File | Description | Rows |
|------|-------------|------|
| `psis_validation.csv` | Early PSIS validation (N=500, different columns) | 500 |
| `svf_validation_17levels.csv` | SVF with 17 coupling levels | ~1000 |
| `svf_validation_20levels.csv` | SVF with 20 coupling levels | ~8000 |
| `hlm_validation_20levels.csv` | HLM with 20 ICC levels | ~8000 |
| `three_layer_validation_20levels.csv` | Three-layer with 20 levels per axis | ~16000 |

## Authoritative Files

The main simulation data is in the parent directory:

- `cf_psis_comprehensive_validation.csv` - **PSIS validation study (N=900)**
- `svf_validation.csv` - SVF case study (N=8,000)
- `hlm_validation.csv` - HLM case study (N=8,000)
- `three_layer_validation.csv` - Three-layer hierarchy (N=16,000)
